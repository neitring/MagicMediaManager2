# MagicMediaManager

MagicMediaManager is a SwiftUI iOS app for tracking favorites across Tours, Musicals, Albums, Video Games, and TV Shows.

## Open in Xcode

1. Clone the repository.
2. Open `MagicMediaManager.xcodeproj` in Xcode.
3. Select a simulator or device and run the `MagicMediaManager` target.

If the project file is not available or you prefer a fresh Xcode project:

1. Create a new **iOS App** project in Xcode named `MagicMediaManager`.
2. Replace the generated sources with the contents of `MagicMediaManager/Sources/MagicMediaManager`.
3. Ensure the bundle identifier and signing settings are correct, then build and run.
